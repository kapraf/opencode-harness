Create and manage a structured task list for the current session.

Use when: task requires 3+ steps; user requests a list; user gives multiple tasks; starting a new task (mark in_progress); completing a task (mark done, add follow-ups).

Skip when: single/trivial task; purely conversational; completable in <3 trivial steps.

States: pending | in_progress | completed | cancelled
One in_progress at a time. Mark complete immediately. Break complex tasks into specific actionable items.
